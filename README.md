# Portfólio de aulas de Framework para Desenvolvimento Web

Este repositório contém o portfólio explicando as aulas e atividades realizadas na disciplina de Framework para Desenvolvimento Web, ministradas pelo professor Alex Fernando de Araújo no segundo semestre de 2024, no IFMS - Câmpus Três Lagoas.

## Como executar

### Pré-requisitos

- Python (versão testada: 3.9.20)
- python-venv

### Instalando e executando

Os comandos a seguir foram executados em um ambiente Linux. Caso esteja usando Windows, recomendo seguir os passos dentro de uma instância do WSL 2.

1. Clone o repositório

```bash
git clone https://github.com/FelipeFlamarini/FpDW2024.2.git
```

2. Acesse a pasta do repositório

```bash
cd FpDW2024.2
```

3. Crie um ambiente virtual

```bash
python -m venv .venv
```

4. Ative o ambiente virtual

```bash
source .venv/bin/activate
```

5. Instale as dependências

```bash
pip install -r requirements.txt
```

6. Inicie o servidor

```bash
python app.py
```
